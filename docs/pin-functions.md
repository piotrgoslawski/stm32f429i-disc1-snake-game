# STM32F429ZIT6 pin function matrix

Every alternate function each GPIO pin can be mapped to (AFn = value for the
GPIOx_AFR register / HAL `Alternate` field). "addl" lists additional functions
(ADC/DAC inputs etc.) that are analog modes, not AF numbers. Generated from
the CubeMX database (see [pinout.md](pinout.md) for source paths); the
**On board** column shows pins already committed to on-board hardware —
prefer unmarked pins when wiring up new external hardware.
